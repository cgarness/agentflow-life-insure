# D0 release record: seal of `public.list_unrestricted_users()` (2026-10-18)

**Status:** applied to production once and verified at the database-role level. The repository closeout added this
record, renamed the forward and rollback files byte-for-byte to the recorded version, and corrected the status
statements. It came from branch `claude/d0-repository-closeout` and is recorded in `WORK_LOG.md`.

## What changed and why
- `public.list_unrestricted_users()` is a `SECURITY DEFINER` function (owner `postgres`) whose body is
  `SELECT * FROM public.profiles;`.
- Before the seal, `PUBLIC`, `anon` and `authenticated` could execute it. Anyone with the public anon key could
  therefore read every agency's profiles through `/rest/v1/rpc/list_unrestricted_users`.
- The migration revoked EXECUTE from `PUBLIC`, `anon` and `authenticated` only. `postgres` (owner) and `service_role`
  keep it.
- Nothing was dropped, the function definition was not changed, and no application data was read or written by the
  migration.
