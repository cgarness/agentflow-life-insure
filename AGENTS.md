# AgentFlow repository instructions

Follow the [project rules](AGENT_RULES.md), [product vision](VISION.md) and latest [work log](WORK_LOG.md).

For every new or changed signed-in CRM interface, read the [AgentFlow design standard](docs/design/AgentFlow_Design_Standard.md) when planning the change and use it again during review. Apply its named color roles, shared components, interaction states, and light and dark themes. Preserve established feature-specific meanings such as configured disposition colors and gold verification actions. Keep changes scoped to the feature being built.

The [visual palette](docs/design/AgentFlow_Design_Palette.pdf) illustrates the standard. Maintain the written standard in this repository when the design changes.
